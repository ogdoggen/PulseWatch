# PulseWatch

Сервис мониторинга HTTP API: проверки по расписанию, история результатов,
инциденты и уведомления о сбое и восстановлении.

## Технологии

Python, FastAPI, Uvicorn, pydantic-settings.

Дальше: PostgreSQL, SQLAlchemy, Alembic, Celery, Redis, HTTPX.

## Текущее состояние

Подготовлен документ требований. Создаётся каркас API и конфигурации.
Первый запуск через Docker Compose — на шаге 0.3.
