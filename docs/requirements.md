| Сущность | Начальные поля |
|---|---|
| **Monitor** | `id`, `name`, `url`, `expected_status_code`, `interval_seconds`, `is_active` |
| **CheckRun** | `id`, `monitor_id`, `scheduled_at`, `completed_at`, `status`, `is_success`, `http_status_code`, `response_time_ms`, `error_type` |

| Запрос | Назначение | Успешный ответ |
|---|---|---|
| `POST /monitors` | Создать монитор | 201 и монитор |
| `GET /monitors` | Получить список | 200 и список |
| `PATCH /monitors/{id}` | Изменить настройки или поставить на паузу | 200 и монитор |
| `POST /monitors/{id}/checks` | Заказать разовую проверку | 202 и идентификатор задания |
| `GET /checks/{id}` | Узнать состояние и результат задания | 200 и проверка |
| `GET /monitors/{id}/checks` | Получить историю | 200 и список проверок |

200 → 500 → 500 → 500 → 200      
Первый 500 увеличивает счётчик, второй открывает инцидент, третий продолжает его, последний 200 закрывает.\
\
500 → 200 → 500    
инцидент не открывается: успех прервал серию неудач.
